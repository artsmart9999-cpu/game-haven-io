# GameHub Portal

Мне нужно создать максимально похожую фронтенд оболочку сайта как тут https://www.crazygames.com/ - сайт с играми

я буду далее работать с компанией https://gamedistribution.com/ и из нее переносить ссылки на игры html5 в мой сайт - который ты создашь

"Build a lightweight, production-ready HTML5 Game Portal inspired by CrazyGames.com. Features: Dark theme (#0f172a), collapsible left sidebar with categories, top search bar with auto-filter, featured game hero banner, responsive game card grid with hover effects. Single game page/modal with 16:9 Iframe container, fullscreen mode, like/dislike buttons, WASD/Mouse controls section, SEO tags text section, and placeholders for AdSense banners (728x90 top, 300x250 sidebar)."
