# GamePortal — портал HTML5-игр с CMS

Пересобираю сайт по вашему шаблону `1.html` (тёмная тема #131726, фиолетовый акцент #8b5cf6, боковое меню, поиск, карусели, сетка игр, модалка с iframe), но лучше: реальные обложки, страницы игр с SEO, админка и база данных.

## Публичная часть

- Сайдбар (260px): логотип «GamePortal», Главная, Популярные, Новинки, категории из базы, разделитель, Рейтинги. На мобильных — выезжающее меню с затемнением, как в шаблоне.
- Шапка: гамбургер, поиск с мгновенной фильтрацией, иконки уведомлений/закладок, кнопка «Войти».
- Главная: карусели «Популярные игры» и «Новые игры» со стрелками прокрутки + сетка «Все игры» с фильтром по поиску и категории.
- Карточка игры: обложка 16:9, название, тег категории, hover — подъём и фиолетовая рамка.
- Запуск игры: модалка с iframe (как в шаблоне) + отдельная страница `/game/<slug>` для SEO — 16:9 iframe, фуллскрин, лайк/дислайк, управление, описание, теги.
- Страницы категорий `/category/<slug>`, страница «Все игры», у каждой свои SEO-теги.
- Заглушки AdSense: 728×90 сверху, 300×250 в сайдбаре контента.
- Русский интерфейс + переключатель EN (RU/EN тексты интерфейса, выбор сохраняется).

## CMS (админка)

- Вход по email + пароль. Роль `admin` хранится отдельно от профилей; доступ к админке только для роли admin.
- `/admin` — список игр: поиск, фильтр по категории, вкл/выкл публикации, «избранное», сортировка.
- `/admin/games/new` и `/admin/games/<id>` — форма игры: название, slug (автогенерация), embed-ссылка GameDistribution, категория, теги, описание, управление, SEO-заголовок и описание, обложка (загрузка файла в хранилище **или** вставка URL), флаги «опубликовано» / «на главной», счётчики.
- `/admin/categories` — CRUD категорий (название RU/EN, slug, иконка, порядок).
- Удаление с подтверждением, валидация полей, уведомления об успехе/ошибке.

## Данные

Включаю Lovable Cloud (база, вход, хранилище файлов):

- `categories` — slug, name_ru, name_en, icon, sort_order
- `games` — slug, title, embed_url, thumbnail_url, category_id, tags, description, controls, seo_title, seo_description, is_published, is_featured, plays, likes, dislikes, created_at
- `user_roles` + функция проверки роли — для доступа админа
- Хранилище `game-thumbnails` для загруженных обложек
- Публичное чтение только опубликованных игр; запись — только admin
- Начальное наполнение: категории и ~12 демо-игр, чтобы сайт сразу не был пустым

## Технические детали

- TanStack Start: маршруты в `src/routes`, чтение данных через loader + TanStack Query, мутации админки — server functions с проверкой роли на сервере.
- Дизайн-токены в `src/styles.css` (палитра из `1.html`), без хардкода цветов в компонентах.
- Лайки/дислайки — инкремент через server function, локальная защита от повторного голоса.
- Первый зарегистрированный аккаунт нужно один раз назначить админом — скажу, как это сделать, после сборки.
